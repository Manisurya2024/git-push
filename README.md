# Pokédex Rails Project

Ruby on Rails Pokédex Explorer – School Assignment

## Requirements
Ruby 3.x
Rails 7.x
SQLite3

## Setup Instructions

Install gems
bundle install

Create database
rails db:create

Run migrations
rails db:migrate

Seed Pokémon data
rails db:seed

## Run the Application
rails server

Open browser:
http://localhost:3000

## Features
- Fetches Pokémon from API
- Stores them in database
- Displays Pokémon list
- Shows Pokémon details
